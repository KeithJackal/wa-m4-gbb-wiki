# VFC mags

Got VFC mags or want to use VFC mags?

{% hint style="warning" %}
Now modifying a WA to run on VFC mags is absolutely doable but it's something you can't reverse once done, neither can you run WA and GHK mags without replacing the magazine catch.

Before you even start, absolutely ensure that you've got a flat nozzle or you've modified a Golden Eagle one beforehand!
{% endhint %}
